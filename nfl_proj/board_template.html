Week __WEEK__ Prop Board

Every DraftKings player prop posted for Sunday and Monday, with the model's lean, calibrated win chance and edge at an assumed price. Rows marked Qualifies pass the paper-trading rules (edge, usage trend, per-game caps).

Win % is the model's probability for the lean side after correcting for its measured overconfidence (backtests showed the raw simulation is too sure of itself). Edge is the expected return per unit at the assumed price; check the real price before betting.
Season log: one square per game this season, filled when the lean side would have won against today's line.
The board is rebuilt on every scheduled lock run with the latest injury reports (ESPN + Sleeper) and lines. Games that have kicked off drop off. Locked marks bets already placed on paper about two hours before that game; Qualifies marks bets that would be placed if the game locked right now.
